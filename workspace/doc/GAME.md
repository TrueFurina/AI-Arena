# 海龟汤游戏机制与角色变体

## 经典海龟汤规则

海龟汤 = 「情境猜谜」：给出一个离奇的**汤面**（谜面情境），玩家通过向知情者提**是非题**（只能得到 是 / 不是 / 不重要 / 是也不是 等限定回答）逐步还原**汤底**（完整真相）。

> **示例汤面**：「一个人走进酒吧，向酒保要了一杯水。酒保却掏出枪指着他。男人说声谢谢，然后走了。」
> **汤底**：男人打嗝，想喝水压惊；酒保用枪「砰」地吓他一跳治好了打嗝，所以男人道谢离开。

## 怎么让 AI 玩：四种设计模式

| 模式 | 机制 | 覆盖维度 | 复杂度 | 阶段 |
|---|---|---|---|---|
| **A. 单 GM + 多提问者** | 脚本/强模型当 GM 守汤底，AI 轮流问是非题 | 推理 | 低 | **M1 首发** |
| B. 双盲互猜 | 两个 AI 各持一半线索，互问互答拼出全貌 | 推理+辩论 | 中 | M2 |
| C. 骗子变体** | 指定一名 AI 说谎/隐瞒，其他人揪出骗子 | 推理+欺骗+伪装 | 高 | M5 |
| D. 辩论裁决 | 多 AI 对真相分歧，辩论说服 GM 定夺 | 辩论 | 中 | M6 |

## 重要洞察

> 纯经典海龟汤（GM 必须诚实答是非题）天然只突出**推理**，**欺骗/伪装几乎测不到**。项目目标要求四维度全覆盖，因此最终架构必须支持**角色化变体（模式 C）**或引入**狼人杀**。

## 角色契约（roles.py）

| 角色 | 输入 | 输出 | 目标 |
|---|---|---|---|
| **GM** | 当前已揭示线索 + 玩家提问 | 是非类限定回答 | 严守汤底，引导但不泄露 |
| **提问者** | 汤面 + 历史问答 | 一个是非题（JSON） | 用最少步数还原汤底 |
| **骗子（M5）** | 汤面 + 被赋予的错误/隐瞒设定 | 回答时选择性说谎 | 不被识破地误导他人 |

## 胜负判定（初步）

- 单局设最大回合数（如 20 轮）。
- 达到回合数或提问者主动「公布汤底」后，比对与真实汤底的还原度。
- **还原度** = 命中的关键事实数 / 总关键事实数。

## 题库结构（puzzles.py，规划）

每条题目建议包含：

```json
{
  "id": "turtle_001",
  "surface": "一个人走进酒吧……",
  "bottom": "男人打嗝……",
  "key_facts": ["男人打嗝", "想喝水压惊", "酒保用枪吓他", "打嗝被治好"],
  "clue_gradient": ["与饮水有关", "与声音有关", "与惊吓有关"]
}
```

`key_facts` 用于计算还原准确率；`clue_gradient` 可用于信息增益的近似估算。
