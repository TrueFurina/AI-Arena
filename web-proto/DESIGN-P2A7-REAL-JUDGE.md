# P2-A / A-7 设计文档 · 真实 LLM 裁判标定

> 状态：**设计定稿 2026-10-13，实现未开始**。对应 ROADMAP P2-A 的 A-7——
> P2-A 唯一剩余项（「受控裁判结论对真实 LLM 裁判是否成立」）。
> 本文只定协议 / 判据 / 失败模式，不含实现。

## 0. 为什么现在做（前置探测实测，2026-10-13）

| 端点 | 探测结果 |
|---|---|
| `zai/glm-4.5-flash` | ✅ **可用**（HTTP 成功） |
| `moonshot/moonshot-v1-8k` | ❌ `AuthenticationError: Invalid Authentication`（停用状态确认） |

⇒ A-7 从「付费 API 阻塞」变为**单端点可执行**。执行环境例外说明：
项目纪律要求跑实验上服务器，但 **API key 不得离开本机**（`.env` 不外传），
服务器也无外网可用 git 同步。故本实验**在本机执行**，用规模控制替代机器控制：
先 sanity（分钟级、8 次调用）验证仪器，再放量（≤300 次调用、分钟级）。
超过阈值则停并如实报告，不擅自放大。

## 1. 要回答的问题（可证伪）

P2-A 用 `judges/biased.py`（**测量误差模型**）得到：

> 收益主体是**多裁判集成**（单点→等权，+3.9~+10.6 全正）；
> **贡献加权**（等权→加权）增量小且不稳（同质组有负值）。

**这不能外推到真实裁判**——受控裁判的偏差形态是自己设定的。
A-7 要回答：

- **Q1**：在**真实 LLM 裁判**上，等权集成是否仍优于单点裁判？
- **Q2**：真实裁判之间的可靠性差异有多大（R = w_max/w_min）？
  R 小 → 加权在理论上就没有空间（f_max = R/(R+2)，R→1 时加权 ≡ 等权）
- **Q3**：受控面板与真实裁判的**结论方向是否一致**？

## 2. 异质性从哪来（必须诚实标注）

本机只有一个可用端点（`zai/glm-4.5-flash`），因此**不能**用「不同模型」造异质性。
改为**同模型、不同裁判人格 prompt**：

| judge_id | 人格 | prompt 要点 |
|---|---|---|
| `strict` | 严格还原度 | 只按汤底中被明确还原的关键事实比例打分，宁严勿宽 |
| `lenient` | 宽松整体印象 | 只要方向对就给高分，看整体 plausibility |
| `keyword` | 字面命中 | 只数玩家还原里出现了多少汤底中的关键实体/动作词 |
| `holistic` | 叙事完整性 | 看还原是否讲出一个自洽故事，忽略个别细节缺失 |

**⚠️ 能力边界（对外不得省略）**：这是**同模型同源**的异质性（prompt 差异），
**不是**跨模型能力差异。因此：
- ✅ 可回答「同一模型下，裁判人格异质 + 集成 是否有效」
- ❌ **不可**回答「多模型裁判共识比单模型裁判好多少」（需要 ≥2 个可用端点）

## 3. 关键设计判断：LLM 失败 → **缺席裁判**，不是 0 分

既有 `players/llm.py::LLMJudge` 在失败时 `return 0.0, "（裁判无响应）"`。
在聚合统计里，**0.0 是一个有效分数**——把它混进去等于让「调用失败」冒充
「裁判打了 0 分」，系统性压低聚合值。这是本项目反复栽过的
「静默 fallback 比报错危险」同一类错误（风格名冒号、λ 惰性）。

**设计**：新模块 `judges/llm_panel.py` 中调用失败或 JSON 解析失败 →
抛 `JudgeUnavailable`；`eval_real_judges.py` 捕获后把该裁判记为
**缺席（absent）**，复用 P2-A 已有的「响应权重比 < 2/3 → 拒绝发布」机制。

- 缺席会真实影响结论（可能被判 REJECTED），这是正确的：它反映「裁判不可靠」
- 缺席率会单独报告（如「4 裁判中 1 个在 18% 用例上不可用」）
- **绝不**把失败折算成分数

## 4. 协议（沿用 P2-A 三条，违反任一条结论无效）

1. **标定集与评测集按题 disjoint**（12 题：前 6 标定 / 后 6 评测）
2. **客观真值唯一**：`char_f1(guess, solution) × 100`（`engine/evaluate.py`）
3. **guess 用 solution 前缀构造质量梯度**（fracs = 0.15/0.35/0.55/0.75/0.90）：
   取整段 solution 会让真值 = 100 被 `[0,100]` 截断，噪声只剩半边 ⇒
   RMSE 被系统性低估、同质裁判也被估出差异（P2-A 实测踩过，R 假性 > 1）

**温度固定 `temperature=0`**：保证同一裁判人格可复现（真实裁判不像受控模型
有显式 RNG 复位，重采样会把「人格差异」与「采样噪声」混在一起，R 会被高估）。
代价：真实裁判的**日间噪声（同一答案重复评会抖）无法直接测得**——如实标注为
本设计的已知缺口（G3 只回答跨人格差异，不回答同人格重复评方差）。

## 5. 成本与规模（先 sanity 后放量，防烧钱）

| 阶段 | 规模 | 调用数 | 目的 |
|---|---|---|---|
| S0 sanity | 2 裁判 × 2 题 × 2 梯度 | 8 | 分数非 0、分布合理、无解析失败 |
| S1 确认性 | 4 裁判 × (6+6) 题 × 5 梯度 | 240 | 标定 + 评测全套 |

单次调用 `max_tokens≈120`（只要 JSON），flash 端点。S1 预计 3–6 分钟。
**缺席率 > 30% 即停**并报告（说明端点不稳，继续烧钱无意义）。

## 6. 预注册判据（先定后跑）

| # | 判据 | 通过条件 | 不过的处置 |
|---|---|---|---|
| G1 | **集成增益**：等权共识 RMSE < 单点裁判 RMSE 的均值 | 30 个评测用例中 ≥20 个改善（2/3） | 如实写「真实裁判上集成增益不成立」 |
| G2 | **加权增量**：加权共识 RMSE ≤ 等权 | 30 个用例中 ≥20 个不劣 | 如实写「加权无增量」（**预期如此**） |
| G3 | **R 值**：报告 4 人格的 RMSE 极差与 R | 报分布；R < 1.25 判「近乎同质，加权无理论空间」 | — |
| G4 | **与受控结论同向**：G1 方向与 P2-A 受控结论（单点→等权为正）一致 | 一致 / 不一致，二选一如实报 | 不一致本身就是发现 |

**不为了凑正结果改判据。** 判据以本文档为准，改动必须留 git 历史。
「不成立」是完全可接受的答案——那意味着 P2-A 的受控结论**只能**在其
受控设定内成立，必须把适用范围缩到「已知 ground truth 的受控环境」。

## 7. 失败模式（pre-declared）

1. **端点超时/限流** → 判缺席（§3），缺席率超阈值即停
2. **人格 prompt 产出同质分数**（R ≈ 1.0）→ G3 如实报「人格异质性不足」，
   此时 G2 的「无增量」是**构造性结果**而非对加权共识的否证
3. **裁判分数分布挤在一端**（全给 90+ 或全给 10-）→ RMSE 被压缩，G1 失效；
   如实报并附分数直方图，不改判据
4. **真实裁判更准于受控**（单点就接近真值）→ 报「集成空间被单点吃掉」，
   仍算 G1 通过与否按数据说话

## 6-A. 判据修订与实现踩坑（sanity 阶段，确认性实验数据产生中）

> **协议声明**：以下修订发生在**确认性实验数据尚未产生**的阶段
> （实验进程已启动，但判据修订依据的是**数学不一致**与**sanity 观测**，
> 不是确认性实验的结果）。原始 §6 判据原文保留不动。

### 修订 1：G1 主判据从「逐用例绝对误差」改为「RMSE 比较」

**原判据**：等权聚合的绝对误差 < 「任取一个裁判」的绝对误差，在 ≥2/3 用例上成立。

**发现的缺陷（sanity 阶段，纯数学）**：设各裁判误差为 `e_j`，则
`|mean(e_j)| ≥ mean(|e_j|)` 恒成立，且**当所有误差同号时取等号**。
也就是说：裁判共享同一方向的偏置（都偏松或都偏严——这恰恰是 LLM 裁判的
常态）时，原判据**恒判「无改善」**，哪怕等权聚合把偏差成功减半。
反向的例子：两名裁判误差 +30 / −30 时等权聚合误差为 0，原判据能识别；
但 +30 / +10 时原判据恒判无改善，而 RMSE 口径判为改善。

**矛盾证据**：sanity 实测（2 裁判）单点 RMSE 36.45 → 等权 25.36（RMSE 口径
集成明显有效），而同一批数据在原判据下只有 1/2 用例「改善」。**同一份数据
两个判据给出相反结论**，说明原判据衡量的不是集成效度。

**修订**：G1 主判据 = `rmse(等权) < mean_j rmse(单点 j)`（与 P2-A 受控实验
同口径）；逐用例改善数降级为辅助读数 G1'，照实报告不参与裁决。
G2/G3 不变。

**反向测试已固化**（`tests/test_real_judge.py`）：同向偏差与异向偏差两组
构造都必须判为「改善」，若有人把判据改回逐用例绝对误差口径，测试立刻变红。

### 实现踩坑（三条，均由 sanity 阶段抓出）

1. **`glm-4.5-flash` 是 thinking 模型**：`max_tokens` 全部消耗在 reasoning，
   实测 `finish_reason=length` / `content` 为空 / `reasoning_content` 1399 字符
   → 既有 `_call` 报 `empty_content`，看起来像「端点不可用」。
   修法：给 `_call` 增加可选 `extra_body`（默认 None，向后兼容），
   zai/ 端点传 `{"thinking": {"type": "disabled"}}`；端点不认则放大预算重试。
2. **脚本漏 `load_dotenv()`**：表现为「所有裁判缺席 + 覆盖率不足」。
   这正是 §3「失败不折算成分数」的价值——配置错误被暴露为缺席，
   而不是被伪装成「裁判都打了 0 分」。守卫逻辑原样报出并停止。
3. **`raise err from exc` 引用已出作用域的 `exc`**：模型返回 JSON 但缺
   `score` 字段时抛 `UnboundLocalError` 而非干净的「不可用」。
   ——教训：新增的 except 分支要用测试覆盖，否则这种错误会伪装成别的问题。

### 成本控制补充：断点续跑

付费实验跑 240 次调用，中断即全丢。故：标定结果与**逐用例**结果都落盘
（`logs/_a7_calib_cache.json`、`logs/_a7_row_cache.json`，原子替换写入），
重跑自动复用；缓存行携带各裁判绝对误差，故续跑无需重算聚合。
