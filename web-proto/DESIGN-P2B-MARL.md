> 状态：**设计定稿 2026-10-13，实现未开始**。本文只定模块边界 / 数据流 / 失败模式 /
> 预注册验收标准，不含实现。所有「现状」均为仓库事实或实测数字。
> 对应 ROADMAP P2-B。执行纪律：训练/评测实验**一律在服务器跑**（见 §9）。

## 1. 目标与边界（先说清不做什么）

**阶段目标**（照抄 ROADMAP 的诚实边界）：让评测台**能评测 MARL agent**——
主持从「固定规则」升级为**可学习策略**，与提问者**联合训练**，并能跑
「LLM 提问 × MARL 主持」混合对局。**不是**提出新的 MARL 算法：双方都是
表格 Q 学习，无函数逼近，无新颖性宣称。

**明确不做**（防范围蔓延，每条都有理由）：

| 不做 | 理由 |
|---|---|
| 提问者状态升级为「汤面语义特征」 | 这是与主持可学习性**正交的独立轴线**（semantic.py 文档已指认），单独立项，避免与 B-1 搅成一个无法归因的实验 |
| 主持「搪塞」动作（无关/不重要/部分是） | 先只做「诚实/说谎」二动作。搪塞是第二个决策轴，列为 B-1b 候选 |
| 接入 MARLlib 等外部 policy | 属 B-2。B-1 的主持策略接口按 Host ABC 实现，外部 policy 将来以同一接口插入，**不需要引擎改动** |
| N×M 评测矩阵泛化 | 属 B-3，直接复用 `Evaluator`，B-1 的矩阵是它的子集 |

## 2. 为什么主持必须「有真实决策」（本设计的第一块基石）

当前 `CategoryHost` 的答案由汤底机械派生（是/否），**决策空间为零**。
一个「可学习的主持」如果最优策略就是固定照实回答，那它学不到任何东西，
联合训练等价于提问者单智能体训练——**实验在设计上就是空的**。

因此主持必须有真实的决策且后果可度量。本项目四维对抗（推理/欺骗/伪装/
辩论）中，「欺骗」正是主持侧的维度：**主持可以在谎与实之间选择**。
这不是外加的机制，而是把项目的核心对抗维度变成可训练的：

> 续5 已实测 LLM 裁判有自偏好偏差 → 「谁来当裁判」是信任问题（P2-A 已解）。
> 同理，「主持是否可信」在海龟汤里从来就是游戏的一部分——**提问者默认
> 主持诚实，这个默认假设本身从未被检验过**。B-1 把它变成可训练的对抗。

## 3. 游戏设计：限量欺骗 · 零和自对弈

### 3.1 主持动作与约束

- 动作（每个问题二选一）：`truth`（按汤底如实答）／`lie`（反转答案：是↔否）
- **谎言配额 k**：每局最多 k 次 lie（默认 k=2，8 轮局）。没有配额时
  「处处说谎」是无成本占优策略，主持的分配问题退化——配额是让
  「对哪些问题花谎言」成为真问题的最小约束
- **谎言成本 λ**：主持每次 lie 付固定成本（默认 λ=0.05）。镜像奖励下
  主持收益 = 2×ΔF1（对提问者还原的伤害）− λ，λ 把「伤害小的谎言」
  过滤掉，只留高伤害谎言。λ/k 均可配，敏感性分析列为后续
  （⚠️ 预实验修订：实测默认 λ=0.05 已落在「全部过滤」区间——主持恒真、
  处理不激活；λ 改为扫描参数，见 §6-A 发现 2）

### 3.2 主持状态（**题目无关**，迁移能力来自构造而非祈祷）

```
state = f"{truth}|{round}|{budget_left}|{asked_before}"
  truth         当前问题的如实答案（是/否）——主持本来就知道汤底，物理合法
  round         第几轮（1..max_rounds）
  budget_left   剩余谎言配额（k..0）
  asked_before  该语义类别此前是否问过（0/1）——主持看得见对局记录
```

状态空间 2×8×(k+1)×2 = 96（k=2 时），两动作。**刻意不含题目 ID**：
与提问者早期 POMDP 教训相反相成——主持的策略必须是「对任何题都成立」
的分配律（例如「谎言花在会被复问确认的类别上更亏」），按题查表的主持
策略在 held-out 上零迁移，正是要避免的。

### 3.3 奖励（零和镜像 + 谎言成本）

```
提问者奖励：不变（重复 −0.5 / 无信息 −0.2 / 有信息 +1.0 / 终局 +2×F1）
主持每步奖励： = −提问者当步奖励 − λ·[action==lie]
主持终局奖励： = −2×F1_提问者
```

要点与已知偏差：
- 因为「是」「否」都算有信息（+1），**说谎不改变提问者的当步奖励**，
  主持的谎言收益全部来自终局 F1 伤害（2×ΔF1）。⇒ 提问者对「被骗」
  的学习信号**只有终局一项**，信用分配穿越 8 轮，预期微弱——这是
  pre-declared 的弱信号风险（§7），不是 bug
- 复问被抓的谎言（先说是后说否）会触发冲突丢弃（§3.4），该类别从还原中
  消失——**对真类别的复问谎言是毁灭性的**（删掉一条真线索），对假类别的
  首问谎言是稀释性的（注入一条假线索）。两者伤害量级不同，主持的分配
  问题因此有真实纹理

### 3.4 提问者反制能力：冲突感知还原（向后兼容，关键设计）

当前 `final_guess` 采纳所有被确认（是）的类别，**对谎言毫无防御**。
新增规则：**同一类别答案冲突（先后答是/否）→ 该类别整体丢弃**。

- **向后兼容性可证明**：诚实主持下同一类别永远同答，冲突不存在，
  该规则是**恒等变换**——现有全部基线数字不变（固化为测试断言）
- 它只在对局中存在谎言时激活，是提问者侧唯一的「抓谎」机制：
  复问同一类别，答案前后不一即暴露。代价是复问 −0.5 且烧一轮，
  「花几轮验证 vs 多问一个新类别」成为提问者的真权衡

### 3.5 新指标：tdhit（真值感知去重命中率）——为什么 dhit 不够

对说谎主持，`dhit`（去重命中率）**可被谎言刷高**：主持见「否」即「是」，
dhit 照单全收，而 F1 被假线索打穿。**用 dhit 评欺骗环境会得出反向结论**。

```
tdhit(transcript, truth_fn) = 不同问句中答案与如实答案一致的数量 / 提问总轮数
```

- 定义进 `engine/evaluate.py`（口径单一真值），`truth_fn` 由调用方注入
  （MARL 层用 `category_answer(puzzle.solution, cat)`）——engine 不耦合
  语义模块，与既有纪律一致
- 欺骗环境下**主指标改为 tdhit**；dhit 照报作为「表观命中」（它被刷高
  本身就是「为什么需要真值感知指标」的实证）；F1 报还原质量

## 4. 训练协议：交替自对弈（不用同步联合更新）

双方表格 Q + 对手策略持续变化 = 非平稳环境。**同步联合更新**在两个
Q 表互相追逐时不收敛到可解释结论（历史上该链的共识实验也栽过同类问题）。
采用交替冻结：

```
Phase H  主持预训练：提问者冻结为 DistinctRandomPolicy（已存在的基线），
         训练主持 Q（E_h 局）→ 主持先学会「打weak提问者」
Phase Q  对抗训练：主持冻结为已训练主持（ε=0.1 随机化冻结，防提问者
         过拟合到单一确定性策略），训练提问者 Q（E_q 局）
Phase C  共演（可选 R 轮）：交替重复 [主持 vs 当前提问者(冻结,评估态)]
         → [提问者 vs 当前主持(冻结,ε=0.1)]；输出共演轨迹诊断（是否震荡）
```

- 交替冻结是**有文档的启发式**，不是有收敛保证的算法——设计文档照实写
- 评估一律 `explore=False`（纯贪心），训练/评估共用同一 episode 循环
  （延续 `run_episode` 的纪律：训练与评估不各写一套）

## 5. 评测矩阵与基线

提问者变体 × 主持变体，held-out 题目划分（默认 8 训练 / 4 测试，seed 固定）：

| 提问者变体 | 含义 |
|---|---|
| Q-honest | 仅对诚实主持训练（= 当前 L2 版本，复跑保证同口径） |
| Q-adv | Phase Q/C 对抗训练产物 |

| 主持变体 | 含义 |
|---|---|
| truthful | CategoryHost（如实） |
| random-liar | 同配额 k，谎言位置均匀随机（**E1 的关键对照**） |
| first-k-liar | 前 k 轮全说谎（退化策略对照） |
| trained-deceptive | Phase H/C 训练产物 |

是否转向「验证」策略）。跨 ≥5 seeds 逐种子报告，不汇总成单值宣称。

## 6-A. 预实验修订记录（2026-10-13 · 确认性实验执行前）

> **协议声明**：以下修订发生在**确认性实验执行之前**的流水线验证阶段，
> 不是看到结果后改判据。原始 §6 判据原文保留在上方不动。修订方向由
> 仪表退化证明决定，不由期望结果决定；修订后判据仍可能失败，失败照实报。
> 三条发现均附本机 sanity 复现证据（分钟级，命令与输出见 git 历史注释）。

### 发现 1：E1 的 tdhit 伤害是恒等式——原判据是坏仪表

**证明**：tdhit = 命中数 / 提问总轮数，且同一问句只取**首次**答案
（`setdefault` 语义，与 dhit 去重口径对齐）。谎言只发生在可决策问题上
（truth ∈ {是,否}，`host_rl._decidable_truth` 守卫），即如实回答本会
是命中的问题。**在提问者不复问的前提下**（sanity 实测复问率恒 0.000，
且发现 3 证明不复问是提问者的理性响应），每次谎言恰好把一个本会命中
的首答变成非命中：

    damage_per_lie = (H/R − (H−L)/R) / L = (L/R) / L = 1/R

与谎言位置、配额 k、主持类型无关。**任何说谎主持的每谎 tdhit 伤害恒等于
1/max_rounds**（8 轮局恒为 0.125）。sanity 实测证实：trained 0.1250 vs
random-liar 0.1250，精确相等。原 E1 因此无法区分任何两个主持——这不是
负面结果，是仪表故障。

**已知边界（复问区间）**：若提问者复问同一问句，第二次起的谎言被首答
去重吸收（tdhit 看不见），恒等式退化为 damage ≤ 1/R。即该区间里主持
倒是有个真实杠杆（谎言花在首问上），但判据方差来源变成提问者行为而非
主持策略，仍不是干净主判据。首答去重本身是与 dhit 对齐的有意设计
（engine/evaluate.py 文档），本次不改语义，仅把边界写清。

**修订**：E1 主判据移到 **F1 每谎伤害**（非退化：取决于谎言命中哪些
关键词与还原句长度，且对任何提问者行为都非退化；sanity 单种子读数
trained 0.026 vs random 0.002），dhit 每谎伤害为辅证（sanity 0.124 vs
0.012）。tdhit 伤害列保留存档并标注恒等式——它自身就是「为什么 tdhit
不能用于 E1」的实证。恒等式（含复问吸收边界）固化为测试断言
（tests/test_marl_host.py），防止指标语义被无意改掉后无人知晓。

### 发现 2：默认 λ=0.05 下欺骗维度整体惰性（§7 五模式之外的新观察）

sanity（λ=0.05）实测：训练主持评估期**谎言数 0.00**——主持退化为
恒真。代数解释：主持谎言收益 = 2×ΔF1 − λ，单谎对 F1 的期望伤害约
0.013（sanity 实测），λ=0.05 > 收益 ⇒ 理性策略是不说谎。λ=0 时主持
恢复说谎（logs/_diag_lambda0.md）。⇒ **默认参数下「可学习主持」这个
处理本身不激活**，确认性实验在默认参数下不成立。
此形态不属于 §7 已声明的五种失败模式，作为第六种观察如实记录，
不事后并入预声明列表。

**修订**：λ 从固定默认值改为**扫描参数** {0, 0.005, 0.01, 0.02, 0.05}，
每个 λ 独立跑全流程并判定 E1'/E2；「主持在该 λ 下是否说谎」作为
区间图报告——这是 §3.1「λ 把伤害小的谎言过滤掉」的定量版（过滤
边界在哪）。E1'/E2 只在主持实际说谎的区间内判定；恒真区间如实报
「处理未激活」。

### 发现 3：E2 在 tdhit 上结构性趋平（理性，非失败）

复问一个被谎过的类别：两问最多贡献 1 个命中（0.5/问），不如问一个
新类别（lied 比例 2/8 时期望 0.75/问）。⇒ 提问者对随机级说谎的理性
响应是**不复问**，E2-on-tdhit ≈ 0 是构造性结果。sanity 实测 Q-adv 与
Q-honest 的 tdhit 全等。

**修订**：E2 主判据不变（按预注册原文，趋平就报趋平），增设 **F1
鲁棒增益**为次要读数（sanity 单种子 Q-adv F1 0.136 vs Q-honest
0.124，+0.012，方向待多样本确认）。

## 7. 失败模式（pre-declared，出现时对号入座而非事后解释）

1. **主持退化为「有配额就花」**：λ 过低或伤害与位置无关 → 分配问题退化。
   诊断：谎言位置分布（若均匀铺满前 k 轮即退化）。此时 E1≈random 是
   预期结果，不是 bug（⚠️ 预实验修订：E1 原判据的 tdhit 伤害是恒等式
   1/max_rounds，任何主持恒等于 random——判据已移至 F1，见 §6-A 发现 1；
   另实测 λ 过高（0.05）时主持恒真，属 §6-A 发现 2 的新观察）
2. **提问者转向复问刷哨**：复问率异常升高 + tdhit 不涨 → 验证策略买贵了。
   诊断：复问率与 tdhit 同报（§5）
3. **共演震荡**：Phase C 双方 Q 值循环追逐不收敛。诊断：共演轨迹逐轮
   指标；震荡则只交付 Phase H+Q 的静态对抗训练，照实写「共演未收敛」
4. **12 题过拟合**：双方状态均题目无关（§3.2），迁移是构造性的；
   仍以 held-out 4 题复核。若 held-out 与训练题结论反向，以 held-out 为准
5. **信号弱**（§3.3 已预告）：提问者抓谎只有终局 F1 一条信号，可能学不到
   任何反制。诊断：Q-adv 与 Q-honest 的复问率差；无差别即照实报
